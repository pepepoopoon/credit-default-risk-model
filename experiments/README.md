# Эксперименты кредитного риска

В `results` сохранены 108 фактически выполненных запусков на синтетических данных.
Каждый JSON фиксирует гипотезу, параметры, validation-порог, test-метрики, стоимость
ошибок, calibration bins, сравнение с константным baseline и диагностические срезы.

## Проверенные сценарии

- learning curve от 120 до 2 000 строк;
- отношение стоимости FN к FP от 1:1 до 150:1;
- независимые seed данных и разбиения;
- пропуски и неизвестные категории;
- сдвиг доли дефолта;
- sigmoid и isotonic calibration;
- совместные стресс-сценарии до 2 400 строк.

## Сводка

Baseline на 360 строках получил average precision `0.4668`, ROC-AUC `0.7578`,
Brier score `0.1488` и среднюю стоимость `0.5694` при выбранном validation-пороге
`0.2594` и отношении FN:FP `5:1`.

По всей серии:

| Метрика | Минимум | Медиана | Максимум |
|---|---:|---:|---:|
| Average precision | 0.0892 | 0.5119 | 0.9135 |
| ROC-AUC | 0.4886 | 0.7786 | 0.8772 |
| Brier score | 0.0458 | 0.1482 | 0.2279 |
| Средняя стоимость | 0.2083 | 0.5712 | 1.1250 |

В 91 из 108 запусков выбранный порог дал меньшую среднюю стоимость, чем константная
вероятность. Абсолютную стоимость нельзя сравнивать между запусками с разными FN:FP:
она интерпретируется только внутри одного cost-сценария. Групповые разрывы по `SEX`
являются диагностикой поведения модели, а не выводом о справедливости.

Синтетические результаты проверяют pipeline и чувствительность решений. Для применения
нужны временная внешняя выборка, независимая проверка risk/fairness и утверждённые цены ошибок.

## Повторный запуск

```bash
PYTHONPATH=src python -m credit_default_risk_model.experiment \
  --output experiments/results/example.json \
  --hypothesis "Проверить выбранный cost-сценарий" \
  --baseline experiments/results/001_baseline.json
```
