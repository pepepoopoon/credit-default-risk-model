# Модель вероятности кредитного дефолта

## Задача

Учебная модель оценивает вероятность дефолта следующего месяца и показывает, как порог
решения связан с ценой ошибок. Это не кредитное решение: результат требует политики риска,
проверки применимого права и участия ответственного специалиста.

## Структура каталогов

- `src/credit_default_risk_model/` — схема, модель, threshold selection и train/evaluate/predict CLI;
- `tests/` — контракт данных, порога, артефакта и сквозной smoke-тест;
- `data/README.md` — источник и схема; `notebooks/` — исполненный smoke-эксперимент;
- `artifacts/` — локальная модель, метрики и test predictions.

## Используемые технологии

Python 3.11, NumPy, pandas, scikit-learn и joblib; pytest и Ruff для QA.

## Требования к окружению

Python `>=3.11,<3.12` и `pip`; Makefile использует `python3.11`. Установка: `make install`.

## Данные

Целевой источник — [UCI Default of Credit Card Clients](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients),
лицензия CC BY 4.0. Реальные строки не включены. `make smoke` создаёт детерминированную
синтетику той же рабочей схемы исключительно для проверки кода.

## Ограничения данных

UCI отражает клиентов Тайваня и исторический период 2005 года; переносимость на другую
страну, время и продукт не предполагается. Поля `SEX`, `EDUCATION` и `MARRIAGE` грубо
кодируют социальные категории. Синтетика не подтверждает реальное качество или fairness.

## Методология и защита от утечек

Разбиение стратифицированное `60/20/20`: train, validation для порога и test для одного
финального отчёта. Импутация, масштабирование, one-hot и калиброванная логистическая
регрессия обучаются только на train; sigmoid calibration выполняется внутренней CV на
train. Порог выбирается на validation минимизацией `FN_cost * FN + FP_cost * FP` по всем
фактически достижимым границам score, включая вариант без положительных решений.
`SEX` не входит в признаки и используется только для диагностики на test. Перед
evaluate/predict проверяются версия артефакта, порядок признаков, target, sensitive attribute
и интерфейс `predict_proba`.

## Baseline и эксперименты

| Эксперимент | Назначение | Метрики |
| --- | --- | --- |
| константная вероятность train | наивный baseline | Brier, ROC-AUC, PR-AUC |
| calibrated logistic regression | интерпретируемый вероятностный baseline | те же + cost и calibration bins |

Числа появляются только после запуска в `artifacts/metrics.json`; репозиторий не выдаёт
smoke-результаты за оценку на UCI.

## Лучшая модель и итоговая метрика

До запуска на версионированном UCI-файле лучшая модель и итоговая метрика не объявлены.
Основные критерии — Brier score и стоимость на test при пороге, выбранном без test.

## Calibration, cost и fairness

Отчёт содержит Brier score, десять calibration bins, confusion matrix и фактическую
стоимость. По каждой группе `SEX` считаются positive rate, TPR и FPR, а также максимальные
разрывы. Это диагностика, не доказательство справедливости: нужны достаточные размеры групп,
доверительные интервалы и нормативное определение допустимых различий.

## Анализ ошибок

`test_predictions.csv` хранит ID, вероятность, пороговый ответ и истину. Анализировать
следует дорогие FN/FP, калибровку в верхних децилях, малые группы и временной дрейф.

## Запуск

```bash
make install
make train
make evaluate
make predict
make test
```

CLI принимают `--help`; стоимости задаются `--false-negative-cost` и
`--false-positive-cost`. Для внешней оценки нужен отдельный размеченный CSV.

## Ограничения модели

Даже калиброванная вероятность не является индивидуальной причиной дефолта. Случайный
split выбран из-за отсутствия времени выдачи в наборе и может завышать переносимость.
Демографические прокси сохраняются в остальных признаках и требуют отдельного аудита.

## Дальнейшие улучшения

Добавить временную внешнюю выборку, bootstrap-интервалы калибровки и групповых разрывов,
проверку альтернативных cost-сценариев и документированную governance-процедуру.
## Статус проекта

Код обучения, cost-порога, fairness-диагностики и synthetic smoke-проверки готов. Итоговая
оценка на зафиксированном UCI-файле и независимый risk/fairness review ещё не выполнены.
